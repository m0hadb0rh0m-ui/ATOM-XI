# ATOM AI X Android
Native Kotlin / Jetpack Compose Android project. Gemini text chat with local SQLite conversation history. Enter your own Gemini API key in Settings. The 3D, image and video tabs are placeholders, not production generators. The API key is stored in app-private preferences; use a backend proxy for production deployment.

## APK
Open **Actions → Build ATOM AI X APK** and download the artifact named `ATOM-AI-X-debug-apk` after a successful build.

Do not commit your API key.
