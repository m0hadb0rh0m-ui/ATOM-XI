# Decisions
1. Preserve the existing default branch; implement V2 on feature/atom-ai-x-v2.
2. Retain the established product name ATOM AI X instead of the specification's temporary NOOR.
3. Implement a static responsive web UI first as a verifiable foundation; this is not a substitute for the required native Android build.
4. Keep unfinished services explicitly marked unavailable. No simulated success.
5. Store drafts and conversation history in localStorage for prototype use only; no claim of encrypted cloud memory.
6. Gemini credentials belong exclusively in backend environment/secret management, never in the frontend or repository.
7. Do not deploy the current unauthenticated backend publicly.
